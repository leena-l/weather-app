# Interactive Weather App

A responsive web application that provides real-time weather updates for cities worldwide. This project focuses on clean UI/UX and efficient API integration.


# Features

Real-time Data: Fetches live weather updates using the OpenWeatherMap API.

Comprehensive Details: Displays temperature (Celsius), sky conditions, humidity, and wind speed.

Search Functionality: Users can instantly find weather data by entering any city name.


# Tech Stack

Frontend: HTML5, CSS3, JavaScript.

API: OpenWeatherMap API.


# Setup

1 - Clone the Repository

2 - Add your API Key - const API_KEY = "YOUR_OPENWEATHERMAP_KEY_HERE"

3 - Launch index.html
